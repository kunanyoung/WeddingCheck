> **기술 제약 명시**: 서버가 없으므로 Web Push는 불가합니다. 브라우저를 닫은 상태에서는
> 알림이 오지 않습니다. 구현은 (a) 앱이 열려 있을 때 `Notification` API + `setTimeout`,
> (b) Service Worker `periodicSync`(Chromium 계열, 설치된 PWA 한정)로 하고, 설정 화면에
> **"브라우저를 완전히 종료한 동안에는 알림이 오지 않습니다"** 를 명시합니다.

## 5. 릴리스 판정 기준 (Definition of Done)

1. P0 요구사항 전체의 수용 기준 충족
2. Lighthouse: Performance ≥ 90, Accessibility = 100, PWA 통과
3. 비행기 모드에서 전체 기능 동작 확인
4. DevTools Network 탭에 앱 데이터 요청 0건 확인
5. 개인정보 차단 테스트 6종(연락처·주민번호·이메일·카드·금액·주소) 통과
6. iPhone Safari · Android Chrome · Windows Chrome 실기 확인
7. 브라우저 데이터 삭제 → 앱이 깨지지 않고 초기 상태로 복구되는지 확인

| --- | --- | --- |
| 브라우저 데이터 삭제로 전체 유실 | 치명적 | 온보딩·설정에 명시 + JSON 백업을 v1.1 최우선 |
| LocalStorage 5MB 한계 | 중간 | 파일은 IndexedDB로 분리. 용량 게이지 제공 |
| Web Push 불가 (서버 없음) | 중간 | 기대치 관리 문구 명시. 인앱 배지를 P0로 |
| 기기 간 동기화 불가 | 중간 | v1은 "1인 1기기" 전제 명시. JSON 내보내기로 수동 이전 |
| 사용자가 메모에 고객 이름 입력 | 높음 | 차단 불가 → 상시 안내 + 온보딩 + 설정 원칙 페이지 |
| 사파리 7일 미접속 시 스토리지 정리 | 중간 | PWA 설치 시 예외. 설치 유도를 P0로 |
