# 04. 화면 설계 · UI 구성

와이어프레임은 데스크톱(≥1024px) 기준이며, 각 화면 끝에 모바일 변형을 적었습니다.

## 0. 공통 셸 (Layout)

```
┌──────────────┬──────────────────────────────────────────────────────┐
│              │  ┌────────────────────────────────────────────────┐  │
│  W  Wedding  │  │ 오늘            2026년 8월 13일 목  🔍 검색 ⌘K │  │  ← Topbar 64px
│     Desk     │  └────────────────────────────────────────────────┘  │
│              │                                                      │
│ ＋ 예식 등록 │                                                      │
│              │                    (Page Content)                    │
│ ▸ 오늘    ③ │                   max-width 1120px                   │
│ ▸ 예식   12 │                                                      │
│ ▸ 일정       │                                                      │
│ ▸ 메모       │                                                      │
│ ▸ 템플릿     │                                                      │
│              │                                                      │
│ ─────────    │                                                      │
│ ⚙ 설정       │                                                      │
│ 진행 12건    │                                                      │
└──────────────┴──────────────────────────────────────────────────────┘
   240px                              flex-1
```

- Sidebar 240px 고정, `bg: secondary(#FFF8F2)`, 우측 1px border
- 활성 항목: 좌측 3px `primary` 바 + `bg` 살짝 진하게 + `aria-current="page"`
- `오늘` 배지 = 지연+오늘 기한 항목 수 (0이면 숨김)
- `예식` 배지 = 진행 중 예식 수
- Topbar: 화면 제목 + 오늘 날짜 + 검색. 스크롤 시 하단 border 등장

**모바일 (<1024px)**
```
┌──────────────────────────────┐
│ ← 오늘            🔍   ⋯     │  ← Topbar 56px (sticky)
├──────────────────────────────┤
│                              │
│        (Page Content)        │
│           padding 16         │
│                              │
│                      ╭────╮  │  ← FAB 56px (예식 등록)
│                      │ ＋ │  │     bottom 80 / right 16
│                      ╰────╯  │
├──────────────────────────────┤
│  오늘  예식  일정  메모  더보기│  ← BottomTab 56px + safe-area

└──────────────────────────────┘
```

**UI 구성 규칙**
- 지연 섹션은 항목이 0건이면 렌더하지 않습니다 (빈 헤더 금지).
- 체크박스는 **홈에서 바로 토글**됩니다. 토글 시 200ms 후 목록에서 fade-out.
- 우측 `[메모]` 는 인라인 메모 입력 팝오버. 화면 이동 없음.
- 예식 라벨(`5/16(토) 그랜드홀`)은 클릭하면 해당 예식 상세로 이동.
- D-Day 예식이 있으면 최상단에 강조 배너: `오늘 예식 · 그랜드홀 13:00 · 남은 항목 5개`
- KPI 4칸은 모바일에서 2×2 그리드.
- 모바일에서 `오늘 메모`/`최근 완료`는 1열 스택, `최근 완료`는 기본 3건 + 더보기.

## 2. 예식 목록 (`/events`)

```
┌────────────────────────────────────────────────────────────────┐
│  [ 진행 중 12 ]  보관함 8            [ D-Day 순 ▾ ] 🔍 필터    │
├────────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────────┐ │
│ │  D-DAY   5/16(토) 13:00 · 그랜드홀                    ⋯    │ │
│ │  5월 셋째 주 1부                                           │ │
│ │  ████████████████████░░░░  27/32 · 84%                     │ │
│ │  ⚠ 지연 1  ·  오늘 5  ·  다음 기한 잔금 확인 (내일)        │ │
│ └────────────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │  D-39    9/21(토) 15:30 · 채플홀                      ⋯    │ │
│ │  ███████████████░░░░░░░░░  22/32 · 69%                     │ │
│ │  다음 기한 보증인원 최종 확인 (D-10 · 9/11)                │ │
│ └────────────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────────────┐ │
│ │  D-123   12/13(토) 12:00 · 가든홀                     ⋯    │ │
│ │  ██████░░░░░░░░░░░░░░░░░░   7/32 · 22%                     │ │
│ └────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

- 카드 클릭 = 상세 진입. `⋯` = 수정 / 복제 / 보관 / 삭제
- 정렬: D-Day 순(기본) / 진행률 낮은 순 / 최근 수정 순
- 필터: 홀 · 지연 있는 예식만 · 이번 달
- D-Day 뱃지 색: `D-0` primary 채움 / `D-7 이내` warning / 그 외 neutral
- 지연이 있으면 카드 좌측에 3px `danger` 스트립
- 데스크톱 ≥1280px에서 2열 그리드, 그 미만 1열

```
┌──────────────────────────────────────────────┐
│  예식 등록                              ✕    │
├──────────────────────────────────────────────┤
│  예식일 *                                    │
│  ┌────────────────────────────────────────┐  │
│  │ 2026-05-16              📅             │  │
│  └────────────────────────────────────────┘  │
│  토요일 · D-276                              │
│                                              │
│  예식 시간                                   │
│  [ 11:00 ] [ 12:00 ] [ 13:00 ] [ 직접 입력 ] │  ← 칩 선택 (클릭 1회)
│                                              │
│  홀                                          │
│  [ 그랜드홀 ] [ 채플홀 ] [ 가든홀 ] [ ＋ ]   │  ← 최근 사용 홀 칩
│                                              │
│  별칭 (선택)                                 │
│  ┌────────────────────────────────────────┐  │
│  │ 예: 5월 셋째 주 1부                    │  │
│  └────────────────────────────────────────┘  │
│  ⓘ 고객 이름을 적지 않아도 날짜·시간·홀로     │
│    충분히 구분됩니다                          │
│                                              │
│  템플릿                                      │
│  ┌────────────────────────────────────────┐  │
│  │ 기본 템플릿 (32항목)              ▾    │  │
│  └────────────────────────────────────────┘  │
│                                              │
│         [ 취소 ]        [ 저장 ]             │
└──────────────────────────────────────────────┘
```

- **필수 입력은 예식일 1개.** 나머지는 칩 1클릭 또는 건너뛰기.
- 시간·홀 칩은 사용 이력 기반으로 자동 정렬(최근 사용 우선).
- 별칭 PII 검증 실패 시:
  ```
  ┌────────────────────────────────────────┐
  │ 010-1234-5678                          │  ← border: danger
  └────────────────────────────────────────┘
  ✕ 연락처는 저장할 수 없습니다. 이 앱은 개인정보를 보관하지 않습니다.
  ```
  → `저장` 버튼 disabled
- 저장 후 상세로 이동 + 토스트 `13개 마일스톤 일정이 만들어졌습니다`
- 모바일은 전체화면 시트(bottom sheet, 90vh), 하단 고정 `저장` 버튼

```
┌────────────────────────────────────────────────────────────────┐

│    │ ☐ 최종인원          D-3 · 5/13    ⚠ 3일 지남            ││
│    │ ☐ 잔금 확인         D-1 · 5/15    내일                   ││
│    ...                                                         │
└────────────────────────────────────────────────────────────────┘
```

**UI 구성 규칙**
- 헤더 원형 진행률 88px, 내부에 `84%`. `success` 색은 100%일 때만.
- 완료된 카테고리는 기본 접힘 + 우측 `✓`. 지연 있는 카테고리는 항상 펼침.
- D-Day인 예식은 `당일` 카테고리 자동 펼침.
- 각 항목 행 높이: 데스크톱 52px, 모바일 60px. 체크박스 24px(터치 영역 44px).
- 완료 항목: 라벨 `muted` + 취소선 없음(취소선은 비활성 항목 전용), 완료 시각 표시.
- `💬` = 항목 메모 있음, `📎` = 첨부 있음. 아이콘 클릭 → 인라인 확장.
- 항목 우클릭/롱프레스 → 기한 수정 / 메모 / 첨부 / 항목 삭제.
- 조건부 비활성 항목: 라벨 취소선 + `폐백 미진행` 뱃지 + 체크박스 disabled.

### 4-1. 일정 탭

```
│  [ 요약 8단계 ]  전체 13단계                                   │
│                                                                │
│  ●━━━ D-180  11/17  계약·시식 예약           5/5  ✓            │
│  ●━━━ D-120  1/16   스드메                   2/2  ✓            │
│  ●━━━ D-90   2/15   청첩장                   2/2  ✓            │
│  ●━━━ D-60   3/17   식권 준비                1/1  ✓            │
│  ●━━━ D-30   4/16   보증인원·혼주·폐백       2/3                │
│  ◉━━━ D-14   5/2    영상·꽃·식권 전달        3/5   ← 현재       │
│  ○━━━ D-7    5/9    식순 원고·폐백 준비      0/3                │
│  ○     D-DAY  5/16   예식 진행                0/1                │
```
- `●` 완료 / `◉` 진행 중 / `○` 예정, 세로 연결선. 지연 구간은 선이 `danger`.
- 마일스톤 클릭 → 해당 항목들만 필터된 체크리스트로 이동.
- 각 마일스톤 우측 `⋯` → 날짜 조정(해당 항목들 기한 일괄 이동).

## 5. 일정 (`/schedule`)

```

│ 13 카테고리 · 35 항목        │   │   ⠿ 계약서 전달       D-175  ✕  │
│ 예식 8건에 사용됨            │   │   ⠿ 계약서 회수       D-170  ✕  │
│ ─────────────────────────    │   │   ⠿ 계약 확인         D-165  ✕  │
│ B웨딩홀                  ⋯   │   │   ＋ 항목 추가                   │

                                   │  ＋ 카테고리 추가                │
                                   └──────────────────────────────────┘
```
- `⠿` 드래그 핸들. 포커스 후 `↑`/`↓` 로도 이동 (a11y 필수, NFR-A11Y-02).
- 항목 클릭 → 인라인 편집(이름, 기한 D-n, 선택 여부).
- `기본 템플릿`은 삭제 불가 — `⋯` 에 삭제 없음, 복제만.
- 사용 중인 템플릿 삭제 시: "예식 8건이 이 템플릿으로 만들어졌습니다. 기존 예식은
  영향받지 않습니다." 안내 후 삭제 허용.

## 11. 마이크로 인터랙션 (Framer Motion)

| 대상 | 동작 | 값 |
| --- | --- | --- |
| 체크박스 | scale 0.9 → 1 + 체크 path draw | 180ms `easeOut` |
| 항목 완료 | 배경 `success-50` 플래시 후 원복 | 400ms |
| 홈 할 일 제거 | opacity 1→0, height→0 | 220ms, 200ms 지연 |
| 원형 진행률 | `strokeDashoffset` 트윈 | 400ms `easeInOut` |
| 진행률 바 | width 트윈 | 300ms `easeOut` |
| 100% 달성 | 원형 scale 1→1.06→1 + 색 전환 | 500ms, 1회 |
| 아코디언 | height auto 트랜지션 | 200ms |
| 토스트 | y 12→0, opacity | 200ms, 5s 후 자동 닫힘 |
| 모바일 시트 | y 100%→0 | 260ms `[0.32,0.72,0,1]` |
| 페이지 전환 | opacity + y 8→0 | 160ms |

`prefers-reduced-motion: reduce` 일 때 위 전부 `duration: 0` 으로 대체 (레이아웃 결과는 동일).
